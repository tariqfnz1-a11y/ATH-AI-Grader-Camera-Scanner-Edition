Settings & Responsible Use

Prototype settings and deployment notes.

Application mode

Manual demo mode

This version stores demo records in this browser using local storage. Camera capture works on supported mobile and desktop browsers over HTTPS. Captured images are temporary for the current session and are not sent to an AI service or synced between devices.

Connecting real AI

  1. Use a secure server-side function or backend.
  2. Store the Gemini API key as a server secret, never in this HTML file.
  3. Send only approved, minimised student data.
  4. Use vision/OCR to transcribe handwriting, then evaluate against the teacher rubric.
  5. Return suggested marks, evidence and confidence per question.
  6. Require teacher approval before publishing grades.
Privacy: This prototype is not a school records system. Use fictional names only. Do not upload identifiable student work or sensitive records to a public GitHub repository or unapproved AI service.

GitHub Pages deployment

  1. Download this single HTML file.
  2. In your GitHub repository, upload it and rename it index.html.
  3. Open repository Settings → Pages.
  4. Select deployment from the main branch and root folder, then save.
  5. Open the published Pages URL after deployment completes.
